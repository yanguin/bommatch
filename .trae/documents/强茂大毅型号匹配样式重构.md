# 强茂/大毅页面型号匹配样式重构方案

## Context

参照微容"型号筛选"页面的单型号/多型号切换交互（[index.html](file:///c:/Users/yangu/Desktop/viiyong/bommatch/index.html) L1015-L1074），统一强茂、大毅两个品牌页面的型号匹配样式，复用现有组件与 CSS 类。已与用户确认：

1. 强茂、大毅都增加"单型号/多型号"切换（复用微容的切换按钮与布局）
2. 强茂去掉"解析→勾选复选框→查询"三步交互，改为直接查询
3. 大毅单型号态只有单个"查询"按钮，功能即解析换算
4. 大毅提示文案"注：暂未接入大毅产品库，当前仅做型号换算，不校验库存。"改为"注：仅做参考"

## 改动文件

只改 `index.html` 和 `renderer.js`，CSS 全部复用现有类（`.filter-section` / `.filter-section-title` / `.filter-actions` / `.stats-grid` / `.stat-card`，定义于 index.html L366-L445），无需新增样式。

### 一、index.html

#### 1. 强茂品牌区（L1231-L1288）重写

- `.filter-section` 标题改为"产品型号"，右侧加 mini text 按钮 `toggleQmInputMode`，文案随 `qmInputMode` 显示"切换多型号/切换单型号"（照抄微容 L1020-L1023 的写法）
- 单型号态 `v-show="qmInputMode === 'single'"`：
  - `el-input` 绑定 `qmSingleText`，placeholder 如 `如: PJQ5588`，`@keyup.enter.native="runQmFilter"`
  - `.filter-actions`：查询（primary → runQmFilter）+ 重置（resetQmFilter）
- 多型号态 `v-show="qmInputMode === 'multi'"`：
  - textarea 绑定 `qmInputText`（:rows="8"），placeholder 保留现有多行示例
  - `.filter-actions`：查询 + 重置
- 删除"已解析型号"复选框区块（L1255-L1271）
- 筛选结果统计（L1274-L1287）：
  - 单型号态：仅"匹配产品数"（现状保留）
  - 多型号态：显示 4 张卡片 输入型号数/已匹配型号/未匹配型号/匹配产品数（数据源 `qmMultiStats`，结构照抄微容 L1204-L1221）
- 右侧空状态（L1616-L1619）文案按模式区分：单型号 `请输入产品型号并点击"查询"`；多型号 `请输入产品型号（每行一个）并点击"查询"`

#### 2. 大毅品牌区（L1290-L1342）重写

- `.filter-section` 标题改为"他牌电阻型号"，右侧加 `toggleDyInputMode` 切换按钮
- 单型号态：
  - `el-input` 绑定 `dySingleText`，placeholder 如 `如: AC0402JR-070RL`，`@keyup.enter.native="runDyConvert"`
  - `.filter-actions`：单个"查询"按钮（primary → runDyConvert）
- 多型号态：
  - textarea 绑定 `dyInputText`（:rows="8"），placeholder 保留
  - `.filter-actions`：查询（runDyConvert）+ 重置（clearDyResult）
- 品牌支持提示（国巨/兴亚/罗姆/威世）保留；红字注改为 `注：仅做参考`
- 右侧空状态（L1662-L1665）按模式区分文案

右侧结果表格（强茂 L1622-L1658、大毅 L1668-L1726）、搜索框、导出按钮均不变。

### 二、renderer.js

#### data（L83-L105）

- 新增：`qmInputMode: 'single'`、`qmSingleText: ''`、`qmMultiStats: null`、`dyInputMode: 'single'`、`dySingleText: ''`
- 删除：`qmParsedItems: []`
- 保留：`qmInputText`（多型号 textarea）、`dyInputText`（多型号 textarea）及其余状态

#### methods

- 新增 `toggleQmInputMode()`：切换 `qmInputMode`，清空 `qmFilterResult` / `qmMultiStats` / `qmSearchText`，清对方态输入（参照 `toggleFilterInputMode` L745-L752）
- 新增 `toggleDyInputMode()`：同上，清 `dyResult` / `dySearchText` / `dyStatusFilter` + 对方态输入
- 重写 `runQmFilter()`（替换 L1041-L1094）：
  - 按模式取输入：单型号 → `[qmSingleText.trim()]`；多型号 → 按换行拆分去空，超过 200 行截断（与微容 `runMultiFilter` L755-L804 一致）
  - 匹配逻辑复用现有实现：构建 partNumber 大写索引 Map，精确命中 + 双向 includes 模糊匹配（原 L1059-L1080 逻辑提取为内部函数）
  - 结果写 `qmFilterResult`；多型号态计算 `qmMultiStats = { totalInputs, matchedInputs, unmatchedInputs, productCount }`（matched = 命中至少 1 个产品的输入行数）
  - $message 按结果数提示（成功/未找到/部分未匹配）
- 删除 `parseQmInput()`（L964-L1038）、`clearQmParsed()`（L1097-L1099）、`toggleQmAll()`（L1101-L1104）
- 新增 `resetQmFilter()`：清 `qmSingleText` / `qmInputText` / `qmFilterResult` / `qmMultiStats` / `qmSearchText`
- `parseDyInput()`（L1163-L1195）改写为 `runDyConvert()`：按模式取输入（单型号取 `dySingleText`，多型号拆行），逐行调用 `convertOneResistor`（L1198-L1258 不变），写 `dyResult` + 消息提示
- `clearDyResult()`（L1261-L1265）：补充清空 `dySingleText`
- `exportQmFilterResult` / `exportDyResult` / `loadQmProducts` / `convertOneResistor` / computed（`filteredQmFilterResult` / `dyStats` / `filteredDyResult`）均不动
