# BOM型号匹配工具

基于 Electron + Vue.js 的桌面应用，支持wrMLCC和qmMOSFET产品型号匹配筛选。

## 功能特性

### 🏢 品牌支持
- **wr（微容）** - MLCC多层陶瓷电容产品匹配
- **qm（强茂）** - MOSFET功率器件产品筛选
- 一键切换，操作便捷

> **品牌只有以上两个。** 型号筛选中的「他牌型号解析」（国巨、村田、华新科等）**不是品牌维度**，
> 只是把别家型号翻译成规格参数（尺寸/介质/容量/偏差/电压），最终一律用于匹配微容产品库。

### 📋 wr - BOM匹配模式
- 选择 BOM 表 Excel 文件进行批量匹配
- **多Sheet支持** - 自动处理Excel中的多个sheet，每个sheet独立处理
- 支持自定义规格描述列名（物料描述、物料规格、PLMTITLE等）
- 按系列筛选（A系列、T系列、B系列、V系列）
- 智能匹配逻辑：
  - **精确匹配优先** - 规格完全一致
  - **忽略偏差匹配** - 规格一致但偏差不同
  - **容差匹配** - 容量在误差范围内
- 匹配结果按系列分列显示（A系列、T系列、B系列、V系列）
- **规格书列** - 每行匹配结果显示对应产品的规格书链接
  - 单个规格书：点击图标直接打开
  - 多个规格书：弹出列表选择打开
- **搜索功能** - 支持按物料描述、匹配状态、匹配型号搜索筛选
- 导出包含原表数据 + 匹配结果（不包含规格书列）

### 🔍 wr - 型号筛选模式
- 按条件筛选 viiyong 产品库
- 支持多维度筛选：
  - 产品型号关键字（支持自动解析填充）
  - 应用场景（A系列、T系列、B系列、V系列）
  - 尺寸代码（11种规格）
  - 温度特性（10种特性）
  - 标称容量（支持pF/nF/uF单位）
  - 容量偏差（9种偏差）
  - 额定电压
- **他牌型号解析** - 输入其他厂家MLCC型号自动解析填充筛选项，最终匹配微容产品：
  - **wr（微容）**：`T106K1206X7T100N2P`（A/T/B/V开头）
  - **gj（国巨）**：`CC0402KRX7R0BB103`（CC开头，AC为车规级）
  - **fh（风华）**：`0603B101K500NT`（4位数字+介质码）
  - **hj（火炬）**：`FCC1206X226K250HT` / `HGC0805R5476M100NSLJ`
  - **ct（村田）**：`GRM32EC72A106KE05L`（GRM）、`GCM155C1H221JA16D`（GCM车规）、`GRT155R71H104KE02D`（GRT车载）、`GCJ188C70J475KE02D`（GCJ高频低阻）、`GJM1555C1H200FB01D`（GJM高频高Q）
  - **ddh（TDK）**：`CGA3E3X7R1H474KT000N`（CGA开头，车规级）、`CNA`系列
  - **三星 SAMSUNG**：`CL05B104KB54PNC`（CL开头）
  - **信昌 PDC**：`FK/FM/FS/FR/FE/FV/FJ/FP/MT/MG/MA` 开头
  - **太阳诱电 Taiyo**：`M + 用途码(A/C/B/S) + 类型码(AS/AR/JC/RL)`，如 `MASR105…`
  - **京瓷 Kyocera**：`CM/CT/CU/AR` 开头
  - **禾伸堂 HolyStone**：`C + 数字尺寸码`，如 `C0603…`
- **规格书列** - 显示每个产品的规格书链接
- 结果搜索和导出Excel

### ⚡ qm - 型号筛选模式
- 批量输入产品型号进行筛选
- 支持多行文本输入（每行一个型号）
- 解析功能 - 自动识别产品型号格式
- 复选框勾选 - 选择需要查询的型号
- 筛选结果显示产品详细参数：
  - 产品型号、封装、极性、配置
  - VDS、VGS、ID、RDS(on)参数
  - Ciss、VGS(th)、Qg等电气参数
- **规格书列** - 显示每个产品的规格书链接
- 导出Excel功能

### 📖 命名规则悬浮窗
- 右下角圆形悬浮按钮，悬停显示"命名规则"提示
- 点击弹出可滚动的长方形悬浮窗，展示命名规则图片（从上到下排列）
- **Ctrl+滚轮缩放** - 放大/缩小图片内容（50%~300%），悬浮窗大小不变
- **标题栏拖动** - 按住标题栏可拖动悬浮窗到任意位置
- 标题栏显示当前缩放比例，支持一键重置缩放

### 🏷️ 界面版本号显示
- 页面标题「BOM型号匹配工具」右侧以小字显示当前版本号（如 `v1.4.4`）
- 版本号读取自 `package.json` 的 `version` 字段，发布新版本（含热更新）后自动跟随显示，无需手工修改

## 使用方法

### 1. wr - BOM匹配
1. 在品牌选择器中选择"wr"
2. 选择"BOM匹配"模式
3. 选择BOM表Excel文件（支持多sheet）
4. 设置规格描述列名（如"物料描述"、"物料规格")
5. 选择匹配系列（A系列、T系列、B系列、V系列）
6. 设置容量容差范围（默认0%）
7. 点击"开始匹配"
8. 查看右侧匹配结果（含规格书列）
9. 可使用搜索功能筛选结果
10. 点击"导出Excel"保存结果（不含规格书列）

### 2. wr - 型号筛选
1. 切换到"型号筛选"模式
2. 设置筛选条件（至少选择一个条件）
3. **他牌型号解析**：
   - 输入其他厂家MLCC型号，点击"解析"自动填充筛选项
   - 支持：wr、gj、fh、hj、ct、ddh、三星、信昌、太阳诱电、京瓷、禾伸堂（见文末格式清单）
   - 解析字段：尺寸、温度特性、容量、偏差、电压
   - 解析结果用于匹配**微容产品库**，他牌型号本身不作为独立品牌
   - gj型号不含标准电压信息，电压字段留空需手动选择
4. 或直接点击"查询"按型号关键字搜索
5. 查看筛选结果（最多显示2000条，含规格书列）
6. 可搜索和导出结果

### 3. qm - 型号筛选
1. 在品牌选择器中选择"qm"
2. 在文本框输入产品型号（每行一个）
3. 点击"解析"按钮，系统自动识别型号格式
4. 在解析结果中勾选需要查询的型号
5. 点击"查询"按钮
6. 查看筛选结果（含规格书列）
7. 点击"导出Excel"保存结果

### 4. 爬取产品数据（首次使用）
```bash
# 爬取wr数据
cd scripts
node fetch_full.js
node json_to_xlsx.js

# 解析qm数据
node parse_qiangmao.js
```

输出的文件移动到 `data/` 目录即可。

### 5. 更新产品数据

当微容官网数据更新时,可以使用自动备份并重新爬取脚本:

**方法一: 一键更新（推荐）**

直接运行脚本,自动备份旧数据并爬取新数据:
```bash
# Windows系统: 双击运行
scripts\backup_and_fetch.bat

# 或在项目根目录执行
.\scripts\backup_and_fetch.bat
```

**方法二: 手动更新**

分步执行备份、爬取、移动操作:
```bash
# 1. 备份旧数据（可选）
# 手动将 data/ 目录下的 JSON 和 Excel 文件移到备份文件夹

# 2. 爬取新数据
cd scripts
node fetch_full.js
node json_to_xlsx.js

# 3. 移动文件到 data 目录
# 将 scripts/ 目录下生成的文件移到 data/ 目录
```

**备份说明:**
- 自动备份脚本会创建以日期命名的备份文件夹（如 `data/archive_20260806/`）
- 旧数据会自动移动到备份文件夹,方便以后查看
- 备份文件夹保留所有历史版本,如需清理可手动删除

## 匹配逻辑说明（wr）

### 优先级
1. **精确匹配** - 容量、电压、温度特性、尺寸、偏差完全一致
2. **忽略偏差** - 容量、电压、温度特性、尺寸一致，偏差不同
3. **容差匹配** - 容量在误差范围内，其他规格一致
4. **未匹配** - 无法找到匹配产品
5. **未解析** - 无法解析物料描述

### 物料描述格式
支持多种格式，如：
- `CCAP,100nF,±10%,50V,X7R,SMD0402`
- `100nF 10% 50V X7R 0402`
- `100nF±10% 50V X7R 0402`

### 温度特性归一化
自动处理别名：
- COG/NPO/NP0 → C0G
- X7R/X5R/X6S等保持原样

## 发布流程（GitHub Releases 热更新）

应用使用 `electron-updater` 通过 GitHub Releases 自动更新，发布新版本时：

1. 修改 `package.json` 中的 `version` 为新版本号（如 `1.4.5`）
2. 运行 `npm.cmd run build:win` 打包（产物自动命名为 `BOM.Setup.1.4.5.exe`，`latest.yml` 文件名自动对齐）
3. 打开 https://github.com/yanguin/bommatch/releases/new
4. Tag 填 `v1.4.5`，点 **Create new tag on publish**
5. 上传 `dist/` 下的三个文件：`latest.yml`、`BOM.Setup.1.4.5.exe`、`BOM.Setup.1.4.5.exe.blockmap`
6. 点 **Publish release**，客户端重启后自动检测并下载更新（下载完成弹窗"立即重启"安装）

> 注意：上传的资产文件名必须与 `latest.yml` 中的 `path` 一致（构建产物已统一为 `BOM.Setup` 命名，直接拖 `dist/` 原文件即可，不要改名）。

## 他牌型号解析格式（输入源，非品牌）

> 以下各厂型号只作**输入源**：解析出规格后统一去微容产品库找替代料，不构成独立品牌。

### wr
- 格式：`系列(1) + 容量码(3) + 偏差(1) + 尺寸(4) + 温度特性(3) + 电压码(3)`
- 示例：`T106K1206X7T100N2P` → T系列, 10µF, ±10%, 1206, X7T, 100V
- 特点：A/T/B/V 开头表示应用场景系列
- 偏差码：B=±0.1pF, C=±0.25pF, D=±0.5pF, F=±1%, G=±2%, J=±5%, K=±10%, M=±20%, P=±100%, Z=+80%/-20%

### gj
- 格式：`CC + 尺寸(4) + 偏差(1) + 内部码(1) + 温度特性(3)+电压码(1) + 版本(2) + 容量码(3)`
- 示例：`CC0402KRX7R0BB103` → 0402, X7R, 10nF, ±10%
- 注意：温度特性段为4位整体（如X7R0），型号不含标准电压值

### fh
- 格式：`尺寸(4) + 介质码(1-2) + 容量码(3) + 偏差(1) + 电压码(3)`
- 示例：`0603B101K500NT` → 0603, X7R(B), 100pF, ±10%, 50V
- 介质码：B=X7R, CG=C0G, X=X5R

### hj
- **FCC格式**：`FCC + 尺寸(4) + 介质(1) + 容量码(3) + 偏差(1) + 电压码(3)`
  - 示例：`FCC1206X226K250HT` → 1206, X5R(X), 22µF, ±10%, 25V
- **HGC格式**：`HGC + 尺寸(4) + 介质码(2) + 容量码(3) + 偏差(1) + 电压码(3)`
  - 示例：`HGC0805R5476M100NSLJ` → 0805, X5R(R5), 47µF, ±20%, 10V

### ct
- **GRM 通用型**：`GRM + 尺寸(2) + 厚度(1) + 介质(2) + 电压(2) + 容量码(3) + 偏差(1) + 规格(3) + 包装(1)`
  - 示例：`GRM32EC72A106KE05L` → 1210, X7S(C7), 100V(2A), 10µF, ±10%
  - 示例：`GRM31A5C2J561JW01D` → 1206, C0G(5C), 630V(2J), 560pF, ±5%
- **GCM 车规级**（对应微容 A 系列）：格式同 GRM
  - 示例：`GCM155C1H221JA16D` → 0402, C0G(5C), 50V(1H), 220pF, ±5%
- **GRT 车载信息娱乐/舒适**（对应微容 T 系列）：格式同 GRM
  - 示例：`GRT155R71H104KE02D` → 0402, X7R(R7), 50V(1H), 100nF, ±10%
- **GCJ 高频低阻抗型**：格式同 GRM
  - 示例：`GCJ188C70J475KE02D` → 0603, X7S(C7), 6.3V(0J), 4.7µF, ±10%
- **GJM 高频高 Q 型**（RF 应用）：格式同 GRM
  - 示例：`GJM1555C1H200FB01D` → 0402, C0G(5C), 50V(1H), 20pF, ±1%
  - 示例：`GJM1555C1HR50WB01D` → 0402, C0G(5C), 50V(1H), 0.5pF, ±0.05pF
- 尺寸码：02=01005, 03=0201, 15=0402, 18=0603, 21=0805, 31=1206, 32=1210, 42=1808, 43=1812, 55=2220
- 偏差码（含 GJM 小容量精密码）：W=±0.05pF, B=±0.1pF, C=±0.25pF, D=±0.5pF, F=±1%, G=±2%, J=±5%, K=±10%, M=±20%

### ddh (CGA车规级)
- 格式：`CGA + 尺寸(1) + 厚度(1) + 寿命试压(1) + 温度特性(3) + 电压(2) + 容量码(3) + 偏差(1) + 包装码`
- 示例：`CGA3E3X7R1H474KT000N` → 0603, X7R, 50V(1H), 470nF, ±10%
- 尺寸码：1=0201, 2=0402, 3=0603, 4=0805, 5=1206, 6=1210, 7=1808, 8=1812, 9=2220
- 温度特性：C0G/NP0/X5R/X6S/X7R/X7S/X7T/X8R/X8L

## 已知解析缺口

以 `data/HSAE-常用MLCC型号-替代料匹配.xlsx`（965行）实测，以下型号**无法解析**，共 215 条：

| 厂家 | 失败数 | 样例 | 原因 |
|------|--------|------|------|
| 太阳诱电 Taiyo | 84 | `JMK212BC6226MG-T`、`LMK107B7225KA-TR` | 前缀规则仅覆盖 `M[ACBS](AS\|AR\|JC\|RL)`，JMK/LMK 等未覆盖 |
| 华新科 Walsin | 70 | `0402N220J500CT` | 4位数字+介质码，但介质码 `N`(C0G) 未覆盖 |
| TDK | 26 | `C1005X7R1H102K050BA` | `C + 公制尺寸(1005/1608/2012)` 格式未支持，仅支持 CGA/CNA |
| 三环 CCTC | 16 | `TCC0402X7R223K500ATM` | 无解析函数 |
| 村田 | 8 | `GCQ1555C1H8R2BB01D` | GCQ 高频系列未支持 |
| KEMET | 7 | `C0402C330J5GAC7867` | 无解析函数 |
| AVX | 3 | `06035C104K4Z2A` | 无解析函数 |
| 风华 | 1 | `0603CG0R82B500NT` | 介质码 `CG` 边界未覆盖 |

**影响范围**：仅影响「型号筛选」中手动粘贴型号的场景。
**BOM 匹配不受影响** —— BOM 模式解析「物料描述」列（如 `CCAP,100nF,±10%,50V,X7R,SMD0402`），965 行全部解析成功。
