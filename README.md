# viiyong BOM型号匹配工具

基于 Electron + Vue.js 的桌面应用，支持微容MLCC和强茂MOSFET产品型号匹配筛选。

## 功能特性

### � 多品牌支持
- **微容品牌** - MLCC多层陶瓷电容产品匹配
- **强茂品牌** - MOSFET功率器件产品筛选
- 一键切换，操作便捷

### �📋 微容 - BOM匹配模式
- 选择 BOM 表 Excel 文件进行批量匹配
- **多Sheet支持** - 自动处理Excel中的多个sheet，每个sheet独立处理
- 支持自定义规格描述列名（物料描述、物料规格、PLMTITLE等）
- 按系列筛选（A系列、T系列、B系列、V系列）
- 智能匹配逻辑：
  - **精确匹配优先** - 规格完全一致
  - **忽略偏差匹配** - 规格一致但偏差不同
  - **容差匹配** - 容量在误差范围内
- 匹配结果按系列分列显示（A系列、T系列、B系列、V系列）
- **规格书列** - 每行匹配结果显示对应产品的规格书链接
  - 单个规格书：点击图标直接打开
  - 多个规格书：弹出列表选择打开
- **搜索功能** - 支持按物料描述、匹配状态、匹配型号搜索筛选
- 导出包含原表数据 + 匹配结果（不包含规格书列）

### 🔍 微容 - 型号筛选模式
- 按条件筛选 viiyong 产品库
- 支持多维度筛选：
  - 产品型号关键字（支持自动解析填充）
  - 应用场景（A系列、T系列、B系列、V系列）
  - 尺寸代码（11种规格）
  - 温度特性（10种特性）
  - 标称容量（支持pF/nF/uF单位）
  - 容量偏差（9种偏差）
  - 额定电压
- **规格书列** - 显示每个产品的规格书链接
- 结果搜索和导出Excel

### ⚡ 强茂 - 型号筛选模式
- 批量输入产品型号进行筛选
- 支持多行文本输入（每行一个型号）
- 解析功能 - 自动识别产品型号格式
- 复选框勾选 - 选择需要查询的型号
- 筛选结果显示产品详细参数：
  - 产品型号、封装、极性、配置
  - VDS、VGS、ID、RDS(on)参数
  - Ciss、VGS(th)、Qg等电气参数
- **规格书列** - 显示每个产品的规格书链接
- 导出Excel功能

## 安装与运行

### 依赖安装
```bash
npm install
```

### 开发模式运行
```bash
npm start
```

### 打包为exe
```bash
npm run build:win
```

打包后的exe文件位于 `dist/win-unpacked/` 目录。

## 使用方法

### 1. 微容 - BOM匹配
1. 在品牌选择器中选择"微容"
2. 选择"BOM匹配"模式
3. 选择BOM表Excel文件（支持多sheet）
4. 设置规格描述列名（如"物料描述"、"物料规格")
5. 选择匹配系列（A系列、T系列、B系列、V系列）
6. 设置容量容差范围（默认0%）
7. 点击"开始匹配"
8. 查看右侧匹配结果（含规格书列）
9. 可使用搜索功能筛选结果
10. 点击"导出Excel"保存结果（不含规格书列）

### 2. 微容 - 型号筛选
1. 切换到"型号筛选"模式
2. 设置筛选条件（至少选择一个条件）
3. 支持输入产品型号自动解析填充条件
4. 点击"查询"
5. 查看筛选结果（最多显示2000条，含规格书列）
6. 可搜索和导出结果

### 3. 强茂 - 型号筛选
1. 在品牌选择器中选择"强茂"
2. 在文本框输入产品型号（每行一个）
3. 点击"解析"按钮，系统自动识别型号格式
4. 在解析结果中勾选需要查询的型号
5. 点击"查询"按钮
6. 查看筛选结果（含规格书列）
7. 点击"导出Excel"保存结果

### 4. 爬取产品数据（首次使用）
```bash
# 爬取微容数据
cd scripts
node fetch_full.js
node json_to_xlsx.js

# 解析强茂数据
node parse_qiangmao.js
```

输出的文件移动到 `data/` 目录即可。

| 系列 | 应用场景 | 说明 |
|------|---------|------|
| **A系列** | 车载动力总成/安全设备 | 汽车动力、安全相关 |

| **V系列** | 通用设备 | 通用电子设备 |

## 匹配逻辑说明（微容）

### 优先级
1. **精确匹配** - 容量、电压、温度特性、尺寸、偏差完全一致
2. **忽略偏差** - 容量、电压、温度特性、尺寸一致，偏差不同
3. **容差匹配** - 容量在误差范围内，其他规格一致
4. **未匹配** - 无法找到匹配产品
5. **未解析** - 无法解析物料描述

### 物料描述格式
支持多种格式，如：
- `CCAP,100nF,±10%,50V,X7R,SMD0402`
- `100nF 10% 50V X7R 0402`
- `100nF±10% 50V X7R 0402`

### 温度特性归一化
自动处理别名：
- COG/NPO/NP0 → C0G
- X7R/X5R/X6S等保持原样

## 注意事项

1. 确保 `data/viiyong_products_full.json` 和 `data/qiangmao_products.json` 文件存在
2. BOM表必须包含规格描述列（可自定义列名）
3. 微容型号筛选至少需要设置一个筛选条件
4. 强茂筛选需要先输入型号并解析，再勾选查询
5. 规格书链接使用域名 `https://www.viiyong.com`
6. 打包前需要在 `build/` 目录放置 `icon.ico` 图标文件
