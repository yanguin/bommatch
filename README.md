# BOM型号匹配工具

基于 Electron + Vue.js 的桌面应用，支持wrMLCC和qmMOSFET产品型号匹配筛选。

## 功能特性

### 🏢 多品牌支持
- **wr品牌** - MLCC多层陶瓷电容产品匹配
- **qm品牌** - MOSFET功率器件产品筛选
- 一键切换，操作便捷

### 📋 wr - BOM匹配模式
- 选择 BOM 表 Excel 文件进行批量匹配
- **多Sheet支持** - 自动处理Excel中的多个sheet，每个sheet独立处理
- 支持自定义规格描述列名（物料描述、物料规格、PLMTITLE等）
- 按系列筛选（A系列、T系列、B系列、V系列）
- 智能匹配逻辑：
  - **精确匹配优先** - 规格完全一致
  - **忽略偏差匹配** - 规格一致但偏差不同
  - **容差匹配** - 容量在误差范围内
- 匹配结果按系列分列显示（A系列、T系列、B系列、V系列）
- **规格书列** - 每行匹配结果显示对应产品的规格书链接
  - 单个规格书：点击图标直接打开
  - 多个规格书：弹出列表选择打开
- **搜索功能** - 支持按物料描述、匹配状态、匹配型号搜索筛选
- 导出包含原表数据 + 匹配结果（不包含规格书列）

### 🔍 wr - 型号筛选模式
- 按条件筛选 viiyong 产品库
- 支持多维度筛选：
  - 产品型号关键字（支持自动解析填充）
  - 应用场景（A系列、T系列、B系列、V系列）
  - 尺寸代码（11种规格）
  - 温度特性（10种特性）
  - 标称容量（支持pF/nF/uF单位）
  - 容量偏差（9种偏差）
  - 额定电压
- **多品牌型号解析** - 输入其他品牌MLCC型号自动解析填充筛选项：
  - **wr**：`T106K1206X7T100N2P`（A/T/B/V开头）
  - **gj**：`CC0402KRX7R0BB103`（CC开头）
  - **fh**：`0603B101K500NT`（4位数字+介质码）
  - **hj**：`FCC1206X226K250HT` / `HGC0805R5476M100NSLJ`
  - **ct**：`GRM32EC72A106KE05L`（GRM开头）
  - **ddh**：`CGA3E3X7R1H474KT000N`（CGA开头，车规级）
- **规格书列** - 显示每个产品的规格书链接
- 结果搜索和导出Excel

### ⚡ qm - 型号筛选模式
- 批量输入产品型号进行筛选
- 支持多行文本输入（每行一个型号）
- 解析功能 - 自动识别产品型号格式
- 复选框勾选 - 选择需要查询的型号
- 筛选结果显示产品详细参数：
  - 产品型号、封装、极性、配置
  - VDS、VGS、ID、RDS(on)参数
  - Ciss、VGS(th)、Qg等电气参数
- **规格书列** - 显示每个产品的规格书链接
- 导出Excel功能

### 📖 命名规则悬浮窗
- 右下角圆形悬浮按钮，悬停显示"命名规则"提示
- 点击弹出可滚动的长方形悬浮窗，展示命名规则图片（从上到下排列）
- **Ctrl+滚轮缩放** - 放大/缩小图片内容（50%~300%），悬浮窗大小不变
- **标题栏拖动** - 按住标题栏可拖动悬浮窗到任意位置
- 标题栏显示当前缩放比例，支持一键重置缩放

## 使用方法

### 1. wr - BOM匹配
1. 在品牌选择器中选择"wr"
2. 选择"BOM匹配"模式
3. 选择BOM表Excel文件（支持多sheet）
4. 设置规格描述列名（如"物料描述"、"物料规格")
5. 选择匹配系列（A系列、T系列、B系列、V系列）
6. 设置容量容差范围（默认0%）
7. 点击"开始匹配"
8. 查看右侧匹配结果（含规格书列）
9. 可使用搜索功能筛选结果
10. 点击"导出Excel"保存结果（不含规格书列）

### 2. wr - 型号筛选
1. 切换到"型号筛选"模式
2. 设置筛选条件（至少选择一个条件）
3. **多品牌型号解析**：
   - 输入其他品牌MLCC型号，点击"解析"自动填充筛选项
   - 支持品牌：wr、gj、fh、hj、ct、ddh
   - 解析字段：尺寸、温度特性、容量、偏差、电压
   - gj型号不含标准电压信息，电压字段留空需手动选择
4. 或直接点击"查询"按型号关键字搜索
5. 查看筛选结果（最多显示2000条，含规格书列）
6. 可搜索和导出结果

### 3. qm - 型号筛选
1. 在品牌选择器中选择"qm"
2. 在文本框输入产品型号（每行一个）
3. 点击"解析"按钮，系统自动识别型号格式
4. 在解析结果中勾选需要查询的型号
5. 点击"查询"按钮
6. 查看筛选结果（含规格书列）
7. 点击"导出Excel"保存结果

### 4. 爬取产品数据（首次使用）
```bash
# 爬取wr数据
cd scripts
node fetch_full.js
node json_to_xlsx.js

# 解析qm数据
node parse_qiangmao.js
```

输出的文件移动到 `data/` 目录即可。

### 5. 更新产品数据

当微容官网数据更新时,可以使用自动备份并重新爬取脚本:

**方法一: 一键更新（推荐）**

直接运行脚本,自动备份旧数据并爬取新数据:
```bash
# Windows系统: 双击运行
scripts\backup_and_fetch.bat

# 或在项目根目录执行
.\scripts\backup_and_fetch.bat
```

**方法二: 手动更新**

分步执行备份、爬取、移动操作:
```bash
# 1. 备份旧数据（可选）
# 手动将 data/ 目录下的 JSON 和 Excel 文件移到备份文件夹

# 2. 爬取新数据
cd scripts
node fetch_full.js
node json_to_xlsx.js

# 3. 移动文件到 data 目录
# 将 scripts/ 目录下生成的文件移到 data/ 目录
```

**备份说明:**
- 自动备份脚本会创建以日期命名的备份文件夹（如 `data/archive_20260806/`）
- 旧数据会自动移动到备份文件夹,方便以后查看
- 备份文件夹保留所有历史版本,如需清理可手动删除

| 系列 | 应用场景 | 说明 |
|------|---------|------|
| **A系列** | 车载动力总成/安全设备 | 汽车动力、安全相关 |

## 匹配逻辑说明（wr）

### 优先级
1. **精确匹配** - 容量、电压、温度特性、尺寸、偏差完全一致
2. **忽略偏差** - 容量、电压、温度特性、尺寸一致，偏差不同
3. **容差匹配** - 容量在误差范围内，其他规格一致
4. **未匹配** - 无法找到匹配产品
5. **未解析** - 无法解析物料描述

### 物料描述格式
支持多种格式，如：
- `CCAP,100nF,±10%,50V,X7R,SMD0402`
- `100nF 10% 50V X7R 0402`
- `100nF±10% 50V X7R 0402`

### 温度特性归一化
自动处理别名：
- COG/NPO/NP0 → C0G
- X7R/X5R/X6S等保持原样

## 发布流程

安装包内置版本校验：安装时自动从 Gitee 拉取 `version.txt` 中的最新版本号进行比对，若安装包版本低于最新版本，将提示"该版本不是最新版本，请联系制作者获取安装包"并阻止安装。

每次发布新版本时：

1. 修改 `package.json` 中的 `version` 为新版本号
2. 同步更新 `version.txt` 为相同版本号
3. 将 `version.txt` push 到 Gitee master 分支
4. 运行 `npm run build:win` 打包

## 支持的MLCC品牌型号格式

### wr
- 格式：`系列(1) + 容量码(3) + 偏差(1) + 尺寸(4) + 温度特性(3) + 电压码(3)`
- 示例：`T106K1206X7T100N2P` → T系列, 10µF, ±10%, 1206, X7T, 100V
- 特点：A/T/B/V 开头表示应用场景系列
- 偏差码：B=±0.1pF, C=±0.25pF, D=±0.5pF, F=±1%, G=±2%, J=±5%, K=±10%, M=±20%, P=±100%, Z=+80%/-20%

### gj
- 格式：`CC + 尺寸(4) + 偏差(1) + 内部码(1) + 温度特性(3)+电压码(1) + 版本(2) + 容量码(3)`
- 示例：`CC0402KRX7R0BB103` → 0402, X7R, 10nF, ±10%
- 注意：温度特性段为4位整体（如X7R0），型号不含标准电压值

### fh
- 格式：`尺寸(4) + 介质码(1-2) + 容量码(3) + 偏差(1) + 电压码(3)`
- 示例：`0603B101K500NT` → 0603, X7R(B), 100pF, ±10%, 50V
- 介质码：B=X7R, CG=C0G, X=X5R

### hj
- **FCC格式**：`FCC + 尺寸(4) + 介质(1) + 容量码(3) + 偏差(1) + 电压码(3)`
  - 示例：`FCC1206X226K250HT` → 1206, X5R(X), 22µF, ±10%, 25V
- **HGC格式**：`HGC + 尺寸(4) + 介质码(2) + 容量码(3) + 偏差(1) + 电压码(3)`
  - 示例：`HGC0805R5476M100NSLJ` → 0805, X5R(R5), 47µF, ±20%, 10V

### ct
- 格式：`GRM + 尺寸(2) + 厚度(1) + 介质(2) + 电压(2) + 容量码(3) + 偏差(1) + 规格(3) + 包装(1)`
- 示例：`GRM32EC72A106KE05L` → 1210, X7S(C7), 100V(2A), 10µF, ±10%
- 尺寸码：02=0402, 03=0603, 05=0805, 06=1206, 08=1210, 55=1812

### ddh (CGA车规级)
- 格式：`CGA + 尺寸(1) + 厚度(1) + 寿命试压(1) + 温度特性(3) + 电压(2) + 容量码(3) + 偏差(1) + 包装码`
- 示例：`CGA3E3X7R1H474KT000N` → 0603, X7R, 50V(1H), 470nF, ±10%
- 尺寸码：1=0201, 2=0402, 3=0603, 4=0805, 5=1206, 6=1210, 7=1808, 8=1812, 9=2220
- 温度特性：C0G/NP0/X5R/X6S/X7R/X7S/X7T/X8R/X8L
