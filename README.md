# viiyong BOM型号匹配工具

基于 Electron + Vue.js 的桌面应用，用于自动匹配 MLCC 型号到 viiyong 产品库。

## 功能特性

### 📋 BOM匹配模式
- 选择 BOM 表 Excel 文件进行批量匹配
- 支持自定义规格描述列名（物料描述、物料规格、PLMTITLE等）
- 按系列筛选（A/T/B/V系列）
- 智能匹配逻辑：
  - **精确匹配优先** - 规格完全一致
  - **忽略偏差匹配** - 规格一致但偏差不同
  - **容差匹配** - 容量在误差范围内
- 匹配结果按首字母分列显示
- 导出包含原表数据 + 匹配结果

### 🔍 型号筛选模式
- 按条件筛选 viiyong 产品库
- 支持多维度筛选：
  - 产品型号关键字
  - 应用场景（A/T/B/V系列）
  - 尺寸代码（11种规格）
  - 温度特性（10种特性）
  - 标称容量（支持pF/nF/uF单位）
  - 容量偏差（9种偏差）
  - 额定电压
- 结果搜索和导出Excel

## 安装与运行

### 依赖安装
```bash
npm install
```

### 开发模式运行
```bash
npm start
```

### 打包为exe
```bash
npm run build:win
```

打包后的exe文件位于 `dist/win-unpacked/` 目录。

## 使用方法

### 1. BOM匹配
1. 启动应用，默认为"BOM匹配"模式
2. 选择BOM表Excel文件
3. 设置规格描述列名（如"物料描述"、"物料规格"）
4. 选择匹配系列（A/T/B/V）
5. 设置容量容差范围（默认0%）
6. 点击"开始匹配"
7. 查看右侧匹配结果
8. 点击"导出Excel"保存结果

### 2. 型号筛选
1. 切换到"型号筛选"模式
2. 设置筛选条件（至少选择一个条件）
3. 点击"查询"
4. 查看筛选结果（最多显示2000条）
5. 可搜索和导出结果

### 3. 爬取产品数据（首次使用）
```bash
cd scripts
node fetch_full.js
node json_to_xlsx.js
```

输出的文件移动到 `data/` 目录即可。

## 匹配逻辑说明

### 优先级
1. **精确匹配** - 容量、电压、温度特性、尺寸、偏差完全一致
2. **忽略偏差** - 容量、电压、温度特性、尺寸一致，偏差不同
3. **容差匹配** - 容量在误差范围内，其他规格一致
4. **未匹配** - 无法找到匹配产品
5. **未解析** - 无法解析物料描述

### 物料描述格式
支持多种格式，如：
- `CCAP,100nF,±10%,50V,X7R,SMD0402`
- `100nF 10% 50V X7R 0402`
- `100nF±10% 50V X7R 0402`

### 温度特性归一化
自动处理别名：
- COG/NPO/NP0 → C0G
- X7R/X5R/X6S等保持原样

## 注意事项

1. 确保 `data/viiyong_products_full.json` 文件存在
2. BOM表必须包含规格描述列（可自定义列名）
3. 型号筛选至少需要设置一个筛选条件
4. 打包前需要在 `build/` 目录放置 `icon.ico` 图标文件
